## أولوية التنفيذ بعد اعتماد الفروق

1. H6: عقد الطلب المشترك، وتوحيد قواعد الضيافة، ثم إعادة اختبار البحث الثاني.
2. H10: المقاسات الصريحة قيد بناء؛ قراءة العدد المطلوب؛ قياس بعد التفصيل.
3. الإشعارات: العقد الثلاثي وشهادة التعارض، ثم الرسائل الصادقة.
4. H4: إصلاح `ST` منفصلًا، ثم بحث الدورين المشترك وتحليل بقايا الفشل.
5. مسارات الضيافة لجميع الأشجار، بما فيها المكتبة، قبل حل الأبعاد ثم بعد التفصيل.
6. C10: تنويع تنظيمات حقيقي قبل الهندسة؛ لا تغيير لمعيار r19.
