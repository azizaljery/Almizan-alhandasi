# الميزان الهندسي — حزمة شيفرة مراجعة وإصلاح الجولة 21

**المصدر:** تقرير `v3-diagnosis-r21.md` عن خط الأساس `3b212e7`.

**مهم جدًا:** هذه حزمة JavaScript ES Modules **مكتملة وقابلة للتشغيل والاختبار بذاتها**. ليست رقعة تلقائية للمستودع؛ لم تتوفر في المحادثة ملفات المحرك الفعلية كاملة، ولذلك **على الوكيل تكييف العقود وربط الدوال الموجودة**. لا تدمج ملفات الحزمة عميانيًا في `dist`، ولا تستبدل AZIZ أو Mizan Score أو معيار r19 المجمد. لا توجد هنا أدلة على نجاح H4 أو C10 أو حالات H11–H15.

## التشغيل

```bash
cd mizan-r21-code-package
node --version   # >= 20
npm test         # 31 اختبارًا مستقلاً
npm run example  # نموذج يوضح نتائج التوليد وإشعار العميل
```

لا توجد تبعيات خارجية ولا اتصال شبكي. الاختبارات هنا على أمثلة اصطناعية صغيرة، **وليست** اختبارات على المستودع الأصلي أو الحالات المختومة.

## الفروق عن اقتراحات التقرير

1. «قريب من المجلس» لا يعني تلقائيًا بابًا مباشرًا. يجب استخراج العلاقات بدلالاتها ومصدرها، ومراجعتها من عقد واحد.
2. مقاس 4×5 يثبت صافيًا في `solve` ويُعاد قياسه من هندسة الجدران الفعلية بعد `realizeV2`. لا تقبل مساحة 20م² إذا كان الضلعان مختلفين.
3. نتيجة `PROVEN_INFEASIBLE` في الحزمة لا تُصدر إلا بعد التحقق من شهادة تعارض منطقي محددة. **أي حد أدنى للمساحة أو العرض يحتاج برهانًا إضافيًا مستقلًا قبل السماح به**؛ `gross > available` مع معامل تقديري ليس دليلًا.
4. `SEARCH_INCOMPLETE` لا يعني استحالة؛ ولا يسمح بعرض نص الاستثناء الداخلي.
5. المسار الخاص بالضيف يعتمد على الأبواب الفعلية؛ فحص التنظيم المبكر ضروري لكنه ليس بديلًا عن فحص التفصيل.
6. فحوص الدورين والمواقف والخصوصية **أولية فقط**؛ لا تُعدّ اعتمادًا إنشائيًا أو مروريًا أو تحققًا نهائيًا من الإضاءة والتهوية.
7. `preliminaryDistance` لا يغير معيار r19؛ الدالة `selectDiverse` تتطلب `frozenDifferent` المستخرجة من المعيار الأصلي.
8. لا تعاد كتابة بنية التوليد القائمة. `generateR21` مثال Adapter يربط المحرك القديم؛ يظل AZIZ وMizan Score المرجع المعتمد للتقييم.

## شروط عدم النشر

- التطوير والمراجعة داخل فرع معزول فقط.
- لا دمج في `main` أو `deploy` ولا نشر على الموقع الحالي دون موافقة صريحة لإصدار محدد.
- H11–H15 محجوبة ولا تُفتح أثناء التطوير؛ تُستخدم مرة واحدة بعد تجميد المحرك وفق بروتوكول المالك.
- مراجعة معماري سعودي مرخص قبل طلب اعتماد النشر؛ والمراجعة الإنشائية متخصصة مستقلة.
