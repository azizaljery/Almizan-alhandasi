# Target Architecture

This page describes intent, not current truth.

Target separation:
- PlannerOutputContract: legal data shape.
- Mizan Score: measurement/evidence authority.
- AZIZ: decision/orchestration authority.
- Engineering Review: scoped verification/findings authority.
- 2D/3D/BOQ: read-only downstream consumers of selected canonical geometry.
- SHARA Final Design: customer-facing final product identity only.
