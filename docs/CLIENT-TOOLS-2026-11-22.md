# أدوات مشروع العميل

تنفيذ الأدوات الست في `/tools.html`، مع دخول من الصفحة الرئيسية، والقائمة المشتركة، وروابط العطاءات والتنفيذ في صفحة المخرجات. يبقى مسار التوليد والاعتماد والتسليم الحالي كما هو.

## الاستخدام

| الأداة | السلوك المتاح |
| --- | --- |
| لوحة الذوق | رفع صور، استخراج ألوان على الجهاز، تعليق على كل صورة، تحليل آخر أربع صور بخدمة Claude الحالية، تحرير التوجيه، وتنزيله أو نسخه. |
| التشطيبات والمشتريات | مكتبة منتجات يدخل العميل اسمها وماركتها ورمزها وسعرها وتاريخه ورابط المورد؛ اختيار لكل غرفة؛ كميات أرضية من الهندسة؛ هدر وعبوات وتكلفة وقائمة CSV. تُعرض خامات الأرضية وألوان الجدران على مجسم المخطط نفسه. |
| استيراد المخطط | صور PNG/JPEG/WebP وPDF متعدد الصفحات يُعرض محليًا؛ معايرة بنقطتين وبُعد معلوم؛ تتبع جدران وغرف وأبواب ونوافذ يدويًا أو بمسودة من Claude؛ مراجعة صريحة قبل إنشاء مستند مرسم قابل للتحرير. |
| الترميم | نسخة أساس مستقلة ومقترح قابل للتغيير؛ عرض منفصل لكل دور؛ تمييز الباقي والإزالة والجديد؛ حصر مساحة الجدران بعد خصم فتحاتها؛ تبادل المقترح مع المرسم دون فقد الأصل. |
| عروض المقاولين | جدول نطاق مرجعي قابل للتعديل؛ كميات مختارة من الرسم دون تسعير ملخصات مكررة؛ قالب CSV؛ عدة عروض؛ إجمالي العرض وإجمالي على كميات المرجع؛ كشف النقص وفروق الوحدات والكميات؛ مقارنة سعر كل بند وتوثيق الاستثناءات. |
| متابعة التنفيذ | أعمال ومسؤول وموقع وميزانية وتواريخ قابلة للتعديل؛ حالات وفحص واستلام موثق بملاحظة وتاريخ؛ صور؛ دفعات لا تتجاوز ميزانية العمل المستلم؛ نسبة تقدم من الأعمال المستلمة وتقرير قابل للتنزيل. |

## البيانات والخصوصية

- بيانات الأدوات في `mizan.client.tools.v1` ضمن مفاتيح دورة حياة المشروع. يُحفظ المشروع الذي بدأ بلوحة ذوق فقط في المشاريع السابقة أيضًا.
- الصور وPDF في IndexedDB تحت `mizan-client-tool-files`. ضغط صور الذوق والموقع يحد أبعادها إلى 1400 بكسل ويزيل بيانات الصورة الإضافية؛ PDF يبقى بملفه الأصلي.
- نسخة احتياطية JSON تشمل المخطط والبيانات والمرفقات. الاستعادة تتحقق من المخطط والمرفقات وتعيد معرّفات الملفات لتجنب استبدال ملفات مشروع آخر.
- الحد الأقصى لمرفقات المشروع 45 ميغابايت؛ ملف PDF حتى 20 ميغابايت. قراءة النسخة الاحتياطية حتى 80 ميغابايت.
- الحفظ محلي ومعلن في الواجهة. لا توجد مزامنة حسابات أو مشاركة بين عدة أشخاص في هذه الإضافة. لا جداول D1 أو ربط تخزين جديد.
- لا يُرسل ملف للمزوّد بمجرد رفعه. إرسال صور التحليل يحدث عند الضغط على زر التحليل وباستخدام رمز خدمة الذكاء الحالي. ملفات PDF تعرضها PDF.js محليًا؛ تُرسل صورة الصفحة المختارة فقط عند طلب التتبع بالذكاء.
- يرفض الحفظ إذا تغيّر ملف الأدوات في تبويب آخر، ويرفض تطبيق تشطيب على مخطط غيّره تبويب آخر منذ فتح الأداة.

## خدمة الصور

`worker/client-tools.mjs` يخدم:

- `GET /api/client-tools/status`: جاهزية الربط، دون كشف مفاتيح.
- `POST /api/client-tools/vision`: تحليل `mood` أو تتبع `plan`.

يُعاد استخدام `ANTHROPIC_API_KEY` و`MIZAN_ACCESS_CODE` و`ANTHROPIC_MODEL` القائمة. رمز دخول العميل يأتي في `X-Mizan-Access-Code`؛ مفتاح المزوّد يبقى في Worker. لا حاجة إلى مفتاح OpenAI أو تعديل صلاحيات D1.

تُرفض الأصول المختلفة، والطلبات غير الموثقة، والصور المخالفة للنوع/ترويسة الملف، والحمولات فوق 4.5 ميغابايت. حد الاستخدام خمس عمليات في الدقيقة لكل IP على النسخة العاملة، مثل حدود الحماية المحلية بالذاكرة؛ ليس سقف فوترة يوميًا موزعًا. إجابة Claude أداة منظمة يُتحقق من إحداثياتها وأنواع غرفها ومراجع فتحاتها قبل إرجاعها للمتصفح.

## الحدود الوظيفية

- تحليل الصور ينتج توجيهًا أو مسودة تتطلب المراجعة، ولا يثبت التفرد أو الملكية أو صحة الأبعاد.
- مقياس الاستيراد من قياس العميل. سماكة الجدران الأولية 20 سم وارتفاع الدور 3.2 م، وكلاهما قابل للتعديل في المرسم ومعلن في الواجهة.
- المنتجات والأسعار من إدخال المستخدم وروابطه؛ لا توجد أسعار سوق أو مخزون حي أو عملية شراء داخل الموقع. خامة المجسم تقريب بصري؛ لا نموذج ثلاثي الأبعاد مطابق لكل SKU. الأبواب والإنارة والأثاث تُدرج بكمياتها اليدوية في قائمة المشتريات.
- تقدير دهان الغرفة من المحيط × الارتفاع قبل خصم الفتحات؛ أساس الحساب ظاهر. لا تشمل تكلفة المنتجات تركيبًا أو شحنًا أو ضريبة غير مدخلة في السعر.
- أداة الترميم لا تستنتج العناصر الحاملة. إزالة الجدار من المقترح تتطلب إقرار مراجعة إنشائية؛ الأعمدة والسلالم خارج أداة الإزالة.
- المقارنة المالية لا تحول العرض الناقص إلى سعر كامل. اختلاف الوحدة يمنع تسعير ذلك البند على كميات المرجع.
- سجل الدفعات توثيق محلي، ولا يحول أموالًا أو يصدر اعتمادًا هندسيًا تنفيذيًا.

## البناء والفحص

```sh
npm ci
npm run build
node tests/client-tools.test.mjs
node --test --test-concurrency=4 tests/*.test.mjs
```

البناء ينسخ PDF.js وملف العامل والخطوط وCMaps والترخيص إلى `dist/vendor/pdfjs` قبل نسخ الأصول العامة. ملفات PDF.js الناتجة غير متعقبة في Git؛ مصدرها النسخة المقفلة في package-lock.

فحص متصفح محلي فقط، بملفات اصطناعية وقاعدة اختبار معزولة:

```sh
node scripts/quality-preview.mjs
# في طرفية أخرى:
node scripts/client-tools-browser.mjs
```

يمكن ضبط `CHROMIUM_PATH` و`TOOLS_EVIDENCE_DIR`. يستعمل السكربت Chromium النظام إن وُجد وإلا متصفح Playwright المثبت. يرفض عنوان إنتاج، ويتحقق من المسارات الست والمجسم الحقيقي وPDF والاستعادة بين سياقين مستقلين، وتباين النص في الفجر والنهار والليل، وشريط الجوال وعدم تجاوز عرضه.

فحص تحليل الذكاء في الاختبارات يستخدم مزوّدًا محاكى؛ جودة تحليل صور العملاء والربط بالمزوّد الحي تحتاج تجربة على الإصدار المنشور برمز الخدمة القائم. لا يُدّعى أنها تحققت عبر المعاينة المحلية.
