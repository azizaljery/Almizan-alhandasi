# Independent numerical benchmark

The frozen test fixture `tests/fixtures/site-solar-spa-reference.json` records eleven synthetic cases computed locally on 2026-10-11 using **pvlib 0.16.1**, installed only into a temporary review directory. pvlib is not an application dependency and no SPA library is redistributed. The reference is a separate implementation, not observed solar measurements or eleven independently published examples.

Primary implementation documentation: [pvlib SPA Python](https://pvlib-python.readthedocs.io/en/v0.16.1/reference/generated/pvlib.solarposition.spa_python.html); underlying [pvlib SPA source](https://github.com/pvlib/pvlib-python/blob/v0.16.1/pvlib/spa.py). We loaded that package's `spa.py` directly to avoid unrelated optional package imports. Its `solar_position` implementation returns `(theta, theta0, e, e0, phi, eot)`; **index 3 is the actual geometric elevation `e0`**, and index 4 is azimuth. The descriptive return-order docstring in this version is inconsistent with those actual variables, so it was not used to select the elevation. No atmospheric-refraction-corrected height is compared.

The published 2003 SPA case uses delta-T 67 seconds and elevation 1830.14 m. Other synthetic cases use elevation 0 m and `spa.calculate_deltat(year, month)`. Pressure/temperature affect the unused refracted output only. Inputs include zero coordinates, night, two hemispheres, near-polar locations, equivalent civil time conventions, leap day and 1901/2099 range endpoints. Each full input and reference output is recorded in the fixture.

Acceptance compares the three-dimensional direction, not raw azimuth near the zenith. The chosen case-set threshold is 0.05°. The observed maximum was **0.008229314°** across these eleven cases. This is a bounded cross-implementation regression criterion, not a global accuracy promise, field verification, or a claim that the simpler NOAA/Meeus calculation achieves SPA accuracy. The application deliberately omits topocentric parallax and atmospheric refraction. See `SITE-SOLAR-SOURCES.md` for formulas, attribution and other limitations.
