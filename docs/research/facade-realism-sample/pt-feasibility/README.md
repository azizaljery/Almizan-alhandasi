# اختبار جدوى تتبّع مسار الضوء — نافذة، الجهة A

- الشيدر والصفحة: `dist/facade-realism/pathtrace.mjs`، `dist/facade-realism-pt.html` (WebGL2 فقط، بلا مكتبات جديدة، خارج حزمة العميل).
- إعادة التشغيل: `node scripts/facade-realism-pt.mjs <مجلد> shot=window spp=24 w=640 h=400 v=A`
- النتيجة (SwiftShader على معالج، لا GPU): 11145 مثلثًا، 8191 عقدة BVH، بناء BVH نحو 32 مللي ثانية، ‏~16 ثانية للتمريرة الواحدة عند 640×400، ‏24 عينة = ~386 ثانية.
- الجودة: ظلال وعمق الفتحة صحيحان، لكن الضجيج ظاهر عند 24 عينة، والكاميرا لا تطابق الـraster تمامًا. الأداء لا يمثل جهاز عميل.
- الخامات المستخدمة ألوان مفترضة (لا نسيج)، وليست منتجًا محددًا.
