# عينة الواقعية v4: هندسة الفواصل (قيد المراجعة، غير مقبولة)

الأوضاع (geo) للمقارنة المعزولة، بالكاميرا والإضاءة نفسيهما:
- `stone-*-old.png`: الكسوة كما كانت (فواصل مرسومة بالخريطة، بلا هندسة).
- `stone-*-flatface.png`: سطح الخامة بلا فواصل وبلا هندسة (يعزل أثر الخامة).
- `stone-*-block.png`: الفواصل هندسة: لوح خلفي أعمق بـ2 سم، وبلاطات 60×30 سم بفاصل 1.2 سم وحواف مشطوبة 4 مم.

أبعاد الكسوة: افتراضات تصوير للعرض، وليست مواصفة منتج موثّقة (غير متحقق).
الخامة: إجرائية، ولا تمثل منتجًا محددًا. المرجع الحقيقي: غير متوفر حتى الآن.
الحالة: لم تُقبل. البلاطات الفردية ما زالت متشابهة اللون، والسطح ما زال يبدو مُصوَّرًا.
إعادة التشغيل: `node scripts/facade-realism-closeups.mjs <مجلد> old,flatface,block stone`
