# الميزان الهندسي — حزمة دمج معاينة معزولة (Staging Preview Only)

**هذه شيفرة تشغيلية للوسم وعرض النواقص والتحقق المسبق، وليست أمر نشر، ولا تعديلًا على AZIZ أو Mizan Score.**

## الوظيفة
- إضافة شريط عربي RTL واضح «نسخة تجريبية — القبول الهندسي غير مكتمل» إلى نسخة المعاينة فقط.
- عرض H3 والاختبارات الأربعة ومشكلات الأبعاد والخصوصية/C9 وستارة C6 وحالة التحقق المستقل.
- منع ظهور الشريط خارج مضيف المعاينة المصرّح به، مع منع اعتبار نتائج الاختبارات ناجحة دون رمز خروج ودليل.
- فحص فرع Git وعناوين الإنتاج والمعاينة قبل التثبيت والنشر التجريبي.
- لا يغيّر كلمات المرور أو قواعد البيانات أو الإعدادات السرية، ولا يشغّل أي نشر أو دمج.

## الدمج في مشروع Vite/HTML يملك `index.html` و`public/`

1. فك الحزمة خارج المستودع الحالي، وانتقل إلى فرع معاينة معزول (ليس `main` أو `deploy`).
2. شغّل من داخل مجلد الحزمة:

```bash
npm test
node scripts/install.mjs --repo /path/to/mizan --preview-url https://YOUR-PREVIEW-HOST.example --production-url https://YOUR-PRODUCTION-HOST.example
```

3. راجع المخرجات (Dry-run افتراضي). ثم بعد الموافقة على الملفات المحلية:

```bash
node scripts/install.mjs --repo /path/to/mizan --preview-url https://YOUR-PREVIEW-HOST.example --production-url https://YOUR-PRODUCTION-HOST.example --apply
```

4. راجع `git diff` في فرع المعاينة. ملف `public/mizan-preview/status.json` **قالب حالات** مبني على تقرير المالك؛ حدّثه فقط بأدلة حديثة، ولا تضع أسرارًا فيه. تحقق أن C9 لم يُسجّل ناجحًا دون مراجعة.
5. شغّل اختبارات المشروع الفعلية وBuild، وسجّل رموز الخروج؛ ولا تستبدل هذه الحزمة الاختبارات الأربعة المعلّقة.
6. قبل نشر المعاينة فقط:

```bash
MIZAN_PREVIEW_DEPLOY=1 MIZAN_DEPLOY_TARGET=staging node scripts/preflight.mjs --repo /path/to/mizan --preview-url https://YOUR-PREVIEW-HOST.example --production-url https://YOUR-PRODUCTION-HOST.example
```

7. **لا تنفذ نشرًا إلا إلى بيئة staging مستقلة** (حساب/مشروع/بيئة مستقلة ببيانات اختبار، ورابط خاص). سجّل `sourceBaseCommit` باعتباره إيداع البداية فقط، ثم حدّد Commit SHA الفعلي للنسخة المنشورة في تقرير التسليم، وتأكد من وجود إمكانية Rollback، اختبر HTTP/الواجهة/2D/3D والتوليد والأخطاء. سجل أدلة أن الإنتاج لم يتغير.

## مهم بشأن توافق المستودع
- تم تجهيز هذه الحزمة لتُنسخ إلى مشاريع Vite أو HTML ذات `index.html` في الجذر ومجلد `public/`.
- إن كان التطبيق Next.js أو هيكلًا آخر، لا تشغّل المثبّت؛ أدرج `<link>` و`<script type="module">` في قالب الصفحة المناسب، وانسخ الملفات إلى المسار العام نفسه، وراجع طريقة الـ build.
- لا يمكن الجزم بأن الحزمة قابلة للدمج آليًا مع الإيداع `1b1531d` أو الفرع الحالي دون الوصول الفعلي إلى ملفاته.
- لا تستخدم `npm install` من هذه الحزمة داخل مشروع الميزان ولا تستبدل `package.json` الخاص به.

## حواجز أمنية
- لا تعتمد الحزمة على `.env` ولا تقرأ كلمات مرور أو مفاتيح. تجنّب وضع أي بيانات سرية في `status.json` لأنه ملف عام.
- فحص `preflight` محلي، لا يثبت عدم تغيير الإنتاج أو سلامة موارد Cloudflare. يجب إثبات العزل بصلاحيات نشر وموارد منفصلة ومراجعة بيئة التشغيل.
- لا يوجد في الحزمة أي كود يفتح H11–H15 أو بذرة التقييم أو يدمج فروعًا أو ينشر إنتاجًا.
- لا تمنح هذه الحزمة اعتمادًا معماريًا أو نظاميًا؛ يتطلب ذلك مراجعة مختص مرخّص.
