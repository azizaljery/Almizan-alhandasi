# الميزان الهندسي — محرك المخطط المحلي

موقع عربي خاص بثلاث خطوات: الأرض، التصميم، والكميات. الهوية بخط Aref Ruqaa والذهبي `#C6A15B` محفوظة.

## استخدام الإصدار

1. أدخل الأبعاد وفعّل الشوارع واختر جهة المدخل. الارتدادات ونسبة البناء افتراضات قابلة للتعديل وليست كود بناء.
2. أنشئ برنامج الغرف من الأعداد أو عدّل الجدول مباشرة. كل سطر غرفة بمساحة صافية وموقع وجانب بالنسبة للمدخل. اضغط «ولّد».
3. اسحب مخطط 2D وكبّر بالعجلة أو بإصبعين، أو اختر الغرفة بالاسم وركّز عليها. في 3D يمكن دخول الغرفة والنظر حولها والتحرك بالأسهم أو WASD أو أزرار اللمس؛ Esc يعيد المنظور.
4. الكميات من الجدران نفسها بعد خصم الفتحات، وللدور الأرضي فقط. أسعار الوحدة فارغة حتى تدخلها، والإجمالي يخص البنود المسعّرة فقط.

إذا تغيّرت المتطلبات يبقى آخر مخطط ناجح ظاهرًا بعلامة «يحتاج تحديثًا». لا يُستبدل عند فشل التوليد، ويمكن استرجاع توليد سابق خلال الجلسة. لا يوجد حفظ تلقائي لمتطلبات المستخدم بين إعادة تحميل الصفحة.

## حدود معلنة

- كتلة مستطيلة ودور أرضي ومدخل واحد. لا L/U أو أفنية أو سلالم أو تصميم للأدوار الأخرى أو مداخل مستقلة.
- كل غرفة تحافظ على مساحتها المطلوبة؛ الأبعاد يتوصل إليها المحرك ولا يضمن طولًا وعرضًا يطلبهما المستخدم نصيًا.
- البحث محدود؛ عدم إيجاد حل ليس إثباتًا لاستحالة التصميم معماريًا. لا يُصغّر المساحات أو يحذف غرفًا لإخفاء الفشل.
- ممر مركزي 1.6 م وفرعي 1.2 م وسماكة خارجية 0.25 م وداخلية 0.15 م وارتفاع 3.2 م؛ افتراضات غير إنشائية، ولا تكفي لإثبات الوصول الشامل.
- الغرف التي لا تلامس واجهة قد تكون بلا نوافذ؛ تظهر أسماؤها في التحذيرات. الخصوصية والتهوية والسلامة تحتاج مختصًا.
- الأثاث توضيحي فقط. التشطيبات وحصر الجدران تقريبيان ولا يخصمان تقاطعات الجدران أو يحسبان أكتاف الفتحات.
- لا تُقدّر الأساسات أو الحديد أو الأنظمة الكهروميكانيكية. هذا ليس جدول كميات تنفيذيًا أو سعرًا شاملًا للمنزل.

## حالة الذكاء

`AI_ENABLED = true` في `dist/assistant.mjs`. التحليل يرسل الطلب إلى Cloudflare Worker على `https://al-mizan-api.ajeryabod.workers.dev/api/assistant`، بينما يبقى مفتاح OpenAI في بيئة الـWorker فقط ولا يوضع في المتصفح.

## ملفات الموقع

`dist/index.html` و`planner.css` للواجهة، `planner.mjs` للهندسة، `layout-worker.mjs` للبحث خارج خيط الواجهة، `plan-view.mjs` للرسم والتكبير، `viewer3d.mjs` للعرض والملاحة، `estimates.mjs` للكميات والتكلفة، `assistant.mjs` لعقد الربط المستقبلي.

الموقع ثابت ولا يحتاج تثبيت حزم. مكتبة Three.js 0.160.0 وخطوط Google تُحمّل في المتصفح. عند تعذر Three أو WebGL تظهر رسالة، ويظل المحرك و2D متاحين. لا توجد حلقة رسم 3D مستمرة؛ يعاد الرسم عند التفاعل أو تغيير المقاس.

## فحص التطوير

باستخدام Node 20 أو أحدث:

```
node scripts/build.mjs
node --test tests/*.test.mjs
```

الفحص الأول يتحقق من الملفات الثابتة ولا يبني خادمًا. الاختبارات تشمل الهندسة والفتحات والاتصال وSVG والتكبير والتحكم في الكاميرا والكميات وعقد الذكاء وخادمه المحاكى. اختبارات 3D تستخدم بدائل Three/DOM؛ لا تثبت الرسم الفعلي عبر WebGL في جميع المتصفحات. لم تُجر مكالمة AI حية أو جلسة QA متصفح في هذا التسليم.

النشر عبر إعداد Sites الحالي الخاص، من `dist/` فقط. `worker/` و`tests/` لا يُرسلان إلى المتصفح.
