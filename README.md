# الميزان الهندسي — محرك المخطط المحلي

موقع عربي خاص بثلاث خطوات: الأرض، التصميم، والكميات. الهوية بخط Aref Ruqaa والذهبي `#C6A15B` محفوظة.

## استخدام الإصدار

1. أدخل الأبعاد وفعّل الشوارع واختر جهة المدخل. يمكنك تحديد سقف مساحة البناء الأرضي بالمتر المربع شاملًا الجدران والممرات. الارتدادات ونسبة البناء افتراضات قابلة للتعديل وليست كود بناء.
2. أنشئ برنامج الغرف من الأعداد أو عدّل الجدول مباشرة. كل سطر غرفة بمساحة صافية وموقع وجانب بالنسبة للمدخل. اضغط «ولّد وقارن البدائل». المسار المتكامل الحالي يولّد بدائل RECT/L/U ويعرض فقط البدائل التي تجتاز التحقق؛ وقد يفشل بديل أو أكثر صراحة إذا لم تلائم القيود الحالية.
3. اسحب مخطط 2D وكبّر بالعجلة أو بإصبعين، أو اختر الغرفة بالاسم وركّز عليها. في 3D يمكن دخول الغرفة والنظر حولها والتحرك بالأسهم أو WASD أو أزرار اللمس؛ Esc يعيد المنظور.
4. الكميات من الجدران نفسها بعد خصم الفتحات، وللدور الأرضي فقط. أسعار الوحدة فارغة حتى تدخلها، والإجمالي يخص البنود المسعّرة فقط.

إذا تغيّرت المتطلبات يبقى آخر مخطط ناجح ظاهرًا بعلامة «يحتاج تحديثًا». لا يُستبدل عند فشل التوليد. يُمنع تصدير الرسم والكميات والتنقل بين البدائل القديمة حتى تحديث المتطلبات أو استرجاع نسخة. يتبع 2D و3D والكميات النموذج المختار نفسه.

## الحفظ والمقارنة — تحديث 20 سبتمبر 2026

- «تنزيل ملف المشروع» يحفظ JSON يتضمن المدخلات الحالية، وصف الفكرة، أسعار الوحدة، الضرائب والاحتياط المفترضين، المخطط المختار، البدائل وآخر خمس نسخ. لا يضم رمز دخول الذكاء أو أسرارًا.
- الحفظ يدوي بتنزيل الملف؛ لا يوجد حفظ سحابي أو تلقائي. استورد الملف لاستعادة العمل بعد إغلاق الصفحة أو على جهاز آخر.
- الاستيراد محدود بـ2 ميغابايت ويتحقق من المخطط والنسخ جميعًا قبل استبدال الجلسة. النماذج المتكاملة (`mizan-p1-integrated`) تُحفظ وتُستعاد بهندستها المضمنة كما هي؛ أما وصفات المشاريع الأقدم فتظل خاضعة لمسار إعادة التوليد المتوافق مع إصدارها. لا يُقبل ملف فاسد أو غير متوافق بصمت.
- يمكن تنزيل الرسم SVG والكميات CSV عربيًا. الأسعار الناقصة تبقى غير مسعّرة، بينما الصفر سعر صريح. الإجمالي جزئي وغير تنفيذي.
- مسار الغرفة المحددة مرسوم عبر محاور الممرات والأبواب المتصلة. تُعرض أطوال الوصول وروابط المجلس بالطعام والمطبخ بالطعام والمستودع والصالة بأقرب غرفة نوم. ليست هذه أقصر مسافات مشي مطلقة ولا اعتمادًا للإخلاء.
- يوضح الفحص اشتراك الضيوف والعائلة في الممر، والغرف المأهولة بلا نوافذ، ونسبة الحركة المرتفعة. لا تُقدّم درجة مضللة على أنها ضمان للخصوصية.
- الفهم المحلي يدعم الأرقام العربية والإنجليزية، ويميز صالة الطعام عن الصالة العائلية، ويعزل النفي إلى الفراغ المعني ويحفظ خصائص الغرف السابقة. تحويل 9×7 إلى 63 م² لا يعني تثبيت الأبعاد؛ تظهر هذه المطالب ضمن غير المنفذ. اللغة الحرة ليست محللًا معماريًا عامًا.

## حدود معلنة

- يدعم المسار المتكامل الحالي أشكال RECT وL وU مع باحة/فناء فعلي في نموذج U، للدور الأرضي فقط. لا توجد سلالم أو تصميم فعلي للأدوار الأخرى أو اعتماد لمداخل مستقلة متعددة ضمن هذا الإصدار.
- كل غرفة تحافظ على مساحتها المطلوبة؛ الأبعاد يتوصل إليها المحرك ولا يضمن طولًا وعرضًا يطلبهما المستخدم نصيًا.
- البحث محدود؛ عدم إيجاد حل ليس إثباتًا لاستحالة التصميم معماريًا. لا يُصغّر المساحات أو يحذف غرفًا لإخفاء الفشل.
- ممر مركزي 1.6 م وفرعي 1.2 م وسماكة خارجية 0.25 م وداخلية 0.15 م وارتفاع 3.2 م؛ افتراضات غير إنشائية، ولا تكفي لإثبات الوصول الشامل.
- الغرف التي لا تلامس واجهة قد تكون بلا نوافذ؛ تظهر أسماؤها في التحذيرات. الخصوصية والتهوية والسلامة تحتاج مختصًا.
- الأثاث توضيحي فقط. التشطيبات وحصر الجدران تقريبيان ولا يخصمان تقاطعات الجدران أو يحسبان أكتاف الفتحات.
- لا تُقدّر الأساسات أو الحديد أو الأنظمة الكهروميكانيكية. هذا ليس جدول كميات تنفيذيًا أو سعرًا شاملًا للمنزل.

## حالة الذكاء

الواجهة تتصل بخادم Cloudflare Worker الخاص بـ«الميزان الهندسي». مفتاح OpenAI يبقى في `OPENAI_API_KEY` داخل أسرار Worker ولا يصل إلى المتصفح. يتطلب التحليل رمز الموقع المحفوظ في السر `MIZAN_ACCESS_CODE`، ويسمح الخادم فقط بأصل موقع Sites المحدد في `ALLOWED_ORIGIN`. نتيجة الحالة `configured: true` تثبت وجود المفتاح فقط؛ لا يصبح الاتصال موثّقًا إلا بعد نجاح طلب تحليل فعلي.

## ملفات الموقع

`dist/index.html` و`planner.css` للواجهة، `planner.mjs` للهندسة والبدائل، `layout-worker.mjs` للبحث والاستيراد خارج خيط الواجهة، `plan-view.mjs` للرسم والتكبير، `viewer3d.mjs` للعرض والملاحة، `circulation.mjs` لشبكة الحركة، `audit.mjs` للفحص، `project.mjs` للحفظ والاستيراد وتصدير الكميات، `estimates.mjs` للكميات والتكلفة، `assistant.mjs` لاتصال خدمة الذكاء المنفصلة.

الموقع ثابت ولا يحتاج تثبيت حزم. مكتبة Three.js 0.160.0 وخطوط Google تُحمّل في المتصفح. عند تعذر Three أو WebGL تظهر رسالة، ويظل المحرك و2D متاحين. لا توجد حلقة رسم 3D مستمرة؛ يعاد الرسم عند التفاعل أو تغيير المقاس.

## فحص التطوير

باستخدام Node 20 أو أحدث:

```
node scripts/build.mjs
node --test tests/*.test.mjs
```

الفحص الأول يتحقق من الملفات الثابتة ولا يبني خادمًا. الاختبارات تشمل الهندسة والفتحات والاتصال وSVG والتكبير والتحكم في الكاميرا والكميات وعقد الذكاء وخادمه المحاكى. اختبارات 3D تستخدم بدائل Three/DOM؛ لا تثبت الرسم الفعلي عبر WebGL في جميع المتصفحات. لم تُجر مكالمة AI حية أو جلسة QA متصفح في هذا التسليم.

آخر تحقق آلي على فرع التحكم بعد إصلاحات ما بعد الـBaseline: 89/89 اختبارًا ناجحًا، بما فيها تكامل RECT/L/U، ثبات مصدر 2D/3D/BOQ، حفظ/استعادة النماذج المتكاملة، إبطال الهوية القديمة بعد تعديل الفتحات، وحدود ملكية Mizan Score/AZIZ/Home Design. اختبارات البرمجة لا تستبدل التحقق المرئي الفعلي على المتصفح أو WebGL في الإنتاج.

## المتبقي قبل وصفه منظومة هندسية مكتملة

1. اختبار تحليل حي للخدمة الخارجية. جرى توحيد عنوان الواجهة واسم `wrangler.toml` على Worker الهندسي `gentle-sun-5ef5` المؤكد في لوحة Cloudflare؛ يتجه العميل إلى `https://gentle-sun-5ef5.aljeryabod.workers.dev/api/assistant`. نشر الواجهة لا ينشر Worker الخارجي، ونجاح فحص الإعداد لا يثبت استجابة OpenAI. خدمة `al-mizan-api` المرتبطة بمشروع الأسهم ليست هدف نشر هذا المشروع.
2. محرك علاقات وخصوصية بقيود مطلوبة، مداخل ضيافة وعائلة وخدمة منفصلة، أجنحة وأبعاد ملزمة؛ النموذج الحالي لا يحقق ذلك بعد.
3. الأشكال RECT/L/U والباحة U أصبحت موجودة في المسار المتكامل؛ ما يزال الملحق المستقل والتعديل الهندسي الحواري الكامل الذي يعيد تقييم جميع القيود بعد كل تغيير ضمن الأعمال اللاحقة.
4. اختبار تفاعلي على المتصفح والأجهزة، ثم مراجعة مختص لأي مخطط يُراد تنفيذه. لا يُعتبر نجاح اختبارات البرمجة اعتمادًا هندسيًا.

واجهة الموقع تُنشر عبر إعداد Sites الحالي الخاص من `dist/`، بينما `worker/server.mjs` يُنشر منفصلًا إلى Cloudflare Worker. لا تُرسل الأسرار مع أي نشر.
